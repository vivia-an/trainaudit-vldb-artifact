### 遇到的问题和解决

| # | 问题 | 原因 | 解决 | 版本特有？ |
|---|------|------|------|-----------|
| 1 | BF16 numpy 不支持 | `.numpy()` 不支持 BF16 | 加 `.float()` | 否 |
| 2 | `tools/__init__.py` 缺失 | 旧版 Megatron 的 tools/ 不是包 | checkout 后 touch | 是 |
| 3 | optimizer hook 不生效 | Megatron distributed optimizer 不是标准 PyTorch optimizer | 改为 patch train_step | 是 |
| 4 | `--mock-data` 不存在 | 旧版无此参数 | 改用假预处理数据 | 是 |
| 5 | `get_batch` KeyError | 不同版本 data key 不同（text/tokens/attention_mask） | 用假预处理数据绕过 | 是 |
| 6 | `from megatron import get_args` 失败 | 不同版本 import path 不同 | inject_trace 直接跑 pretrain_gpt.py | 是 |
| 7 | `pretrain()` 签名变化 | 不同版本参数不同 | try/except 多种调用方式 | 是 |
| 8 | idx header 9 bytes vs 8 bytes | 不同版本 idx 格式不同 | 用 9 bytes header | 是 |
| 9 | idx sequence_lengths 校验失败 | 某些版本有额外校验 | 待修 | 是 |
| 10 | 参数重复（--bf16 两次） | generate_scripts 拼接逻辑 bug | 重写参数拼接，按 key 去重 | 否 |
| 11 | 参数缺值（--tensor-model-parallel-size 无数字） | split 去重把值也去掉了 | 按 `--key value` 为单位去重 | 否 |
| 12 | bug 触发参数缺失 | 自动分析 fix diff 不够准确 | 手动标注 + LLM 分析 | 否 |

**关键发现：12 个问题中 8 个是版本特有的**——说明跨版本复现的主要障碍是框架 API/格式的不兼容，而非 trace 系统本身的问题。
