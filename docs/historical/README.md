# Historical documents

Carried over from the paper repository as it stood before the VLDB reformat. They describe
a **different tree** and reference files that are not in this artifact — `icml2025.sty`,
`PAPER_STORY.md`, `main_cn.tex`, `story_sigmod.md`, figures that were never produced.

Kept for provenance. Do not use them to navigate this repository: `../../README.md` and
`../CLAIM_TO_ARTIFACT_MAP.md` describe what is actually here.

| File | What it was |
|---|---|
| `REPO_INDEX.md` | navigation index for the ICML-era paper repo, with line numbers into a `main.tex` that has since been rewritten |
| `artifact_checklist.md` | SIGMOD-era sharing plan; its open questions (the 0/17-vs-1/17 conflict, the 17/19 denominator) are resolved in `../GAP_AUDIT.md` |
| `FIGURE_BRIEF_FOR_DESIGNER.md`, `FIGURE9_DESIGN_BRIEF.md` | briefs for figures, several of which were never drawn |
